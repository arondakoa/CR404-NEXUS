# Hinweis

Dieses Repository ist ein Produkt-Dossier für CR404 NEXUS.
Es enthält Texte und Markenstills. Es enthält keinen Anwendungscode,
keine Geschäftsgeheimnisse in Form von Implementierung und keine Zugangsdaten.

Die Arbeitsrepositories bleiben privat.
Namen der Module werden von arondakoa für diese Produktfamilie verwendet.
RoboCop404 bezeichnet dieses eigene Modul und keinen Film.

Die Bilder unter `media/` sind eigens für dieses Dossier erzeugte Markenstills.
Sie sind keine Screenshots einer ausgelieferten Oberfläche.

Die Clips unter `media/demo/` zeigen Oberflächen im Simulationsmodus mit Beispieldaten.
Alle Zahlen darin sind Demo-Werte und im Bild als solche beschriftet.
Sie sind kein Umsatz- oder Renditenachweis.

Stand der Produktaussagen: Oktober 2026.
Was noch Skelett ist, ist im README als Skelett bezeichnet.
