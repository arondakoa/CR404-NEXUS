# Forge

![Forge](../media/forge.jpg)

Die App-Fabrik.
Man beschreibt, was man braucht. Forge plant, baut, stylt, prüft und legt das Ergebnis als Projekt ab.

## Die fünf Rollen

| Rolle | Arbeit |
| --- | --- |
| Architect | Aus dem Satz werden Struktur und Stack. Erst eine Heuristik, dann Verfeinerung, wo der Fall nicht in die Schublade passt. |
| Builder | Frontend und Backend mit echten Routen. Fällt die Modellstrecke aus, bleibt ein statisches Gerüst, das trotzdem steht. |
| Styler | Layout und Responsive. Heute ein festes, gutes Theme. Ein Theme pro Auftrag ist der offene Punkt. |
| Tester | Startet das gebaute Backend wirklich und fragt die Gesundheit ab. Kein angehaktes Kästchen ohne Prozess. |
| Shipper | Lokales Git-Commit pro Projekt. Push nur mit ausdrücklichem Auftrag und einem Remote. Nichts veröffentlicht sich selbst. |

## Vorlagen, die es schon kennt

Forge muss die Welt nicht neu erfinden, wenn die Familie schon Produkte hat.

| Vorlage | Was der Kunde bekommt |
| --- | --- |
| AL Messenger | Chat, Räume, Presence |
| Tante Emma | Shop plus B2B-Desk |
| Music Video Studio | Die Studio-Fläche |
| Landing | Eine schlichte Seite |

Die Vorlagen zeigen auf die echten Produkte. Forge kopiert die Idee in ein neues Projekt, nicht die privaten Schlüssel und nicht die Werkstatt.

## Allein

Eine Agentur, ein Gründer, ein interner Builder: Forge ohne NEXUS.
Die Fläche ist eine eigene GUI. Der Auftrag erzeugt ein Verzeichnis, das hochfährt.
Man muss weder Krypto noch einen Laden wollen, um eine Landingpage oder einen kleinen Dienst aus einem Satz zu bekommen.

## In der Suite

Forge ist die Werkbank, die neue Module in dieselbe Familie legt.
Eigene Namen, eigenes Präfix, kein Zusammenstoß mit RoboCop, Dagobert oder dem Shop.
Was Forge ausliefert, kann später als weiteres Geschäft an dieselbe Kasse.

## Stand

Architektur, Agenten, GUI, Vorlagen: da.
Ein echter Lauf, der Code schreibt, das Backend startet und lokal committet: gelaufen, nicht behauptet.
Remote-Push: aus, bis jemand es sagt.
Theme pro Auftrag: noch nicht.

Der nächste Schritt, der einen Kunden spürbar macht: ein Auftrag, ein eigenes Aussehen, eine Übergabe, die ohne den Autor startet.
